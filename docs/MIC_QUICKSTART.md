# MIC inference quickstart

The public quickstart uses one inference-only member from the frozen
strain-holdout family. It demonstrates checkpoint download, strict loading,
input validation, and MIC prediction without distributing optimizer or
auxiliary-classifier state.

It is **not** the seven-member ensemble used for paper-level evaluation and its
single prediction must not be quoted as a benchmark metric or prospective
activity claim.

## Install and download

```bash
git clone --branch v0.1.0 https://github.com/DragonDescentZerotsu/ApexOracle-Core.git
python -m pip install "./ApexOracle-Core[inference]" huggingface_hub

huggingface-cli download Kiria-Nozan/ApexOracle-Core \
  apexoracle_mic_strain_group0_member0_inference.pth \
  example_text_only_dbaasp_2136_atcc_4965.pt \
  --revision 459026cf4ae4e4e38ce5d2cae16ee3871d0a81df \
  --local-dir apexoracle-core-assets
```

When running from a source checkout, replace the first command with
`python -m pip install -e ".[inference]"`.

## Predict

```bash
apexoracle-predict-mic \
  --checkpoint apexoracle-core-assets/apexoracle_mic_strain_group0_member0_inference.pth \
  --input apexoracle-core-assets/example_text_only_dbaasp_2136_atcc_4965.pt \
  --device cpu \
  --verify-checkpoint-sha256 007c8f34cbc2d5fb4d26b0b5261cd697a4d84d85551b03eb29be492153589341 \
  --verify-input-sha256 48527beb21111ac45107d2f61bd8262109dd63e4e950ae6d89bc35f63b569f3c
```

The checkpoint predicts the paper target
`z = -log10(MIC_um / 10)`. The CLI returns both `prediction_z` and the
inverse-transformed `predicted_mic_um`. The verified CPU result is
`z = -0.0717465281`, corresponding to `11.79631996 µM`.

The example bundle contains a precomputed molecule embedding and strain-text
embedding. It exists to test the released model path without requiring the DLM
or Med-LLaMA producer environments. New inputs should be generated by the
versioned MDLM and Core strain-text producers and assembled with the schema
validated by `apexoracle.prediction.hierarchical_mic`.

Asset revision, sizes, hashes, source-checkpoint provenance, and the verified
output are frozen in
[`assets/manifests/core_mic_quickstart.json`](../assets/manifests/core_mic_quickstart.json).
The source/data license boundary is described in [`DATA_NOTICE.md`](../DATA_NOTICE.md).
